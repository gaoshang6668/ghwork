# 工厂仓储物料消耗预测与 AGV 配送调度系统

> 制造智能技术课程设计｜B/S Demo 原型
> 技术栈规划：Vue3 + Element Plus + FastAPI + SQLite + PyTorch
> 算法规划：LSTM 时序预测、Apriori 关联规则挖掘、蚁群算法 AGV 路径仿真

## 项目简介

本项目模拟离散制造工厂仓储物流业务，目标实现**物料消耗预测‑库存预警‑生成配送任务‑AGV 调度仿真**业务闭环。
> 本系统为课程演示 Demo，**不对接真实 AGV 硬件，AGV 仅软件仿真**。
> 项目采用 Vibe Coding AI 辅助开发，使用 Git 做版本管理。

计划落地 3 项制造智能技术：

1. LSTM：工位物料消耗时序预测，输出结果用于库存补货预警
2. Apriori 关联规则挖掘：分析领料工单，推荐配套物料一同配送
3. 蚁群算法：完成 AGV 配送任务路径规划仿真

## 数据集使用

数据集存放路径：`D:\gh\ghwork\data`
⚠️数据集说明：本项目无真实企业数据、无外部下载公开数据集，全部数据集由项目内`generate_dataset.py`脚本自建仿真生成。

1. 生成原始模拟数据集

cd data
python generate_dataset.py

自动生成 4 份 csv 原始模拟工业数据，文件夹不存在会自动创建。

2. 执行数据预处理

python data_preprocess.py

- 完成缺失值、异常值、重复记录处理；时间格式标准化；业务外键校验
- 输出清洗后数据至 `data/processed/`，同时生成 Apriori 算法的工单事务集

> 
> 本项目无企业真实数据，全部为 Python 仿真车间领料数据集。
