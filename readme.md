# 工厂仓储物料消耗预测与 AGV 配送调度系统
> 制造智能技术课程设计｜B/S Demo 原型
> 技术栈：FastAPI + SQLite + HTML/CSS，集成时序预测、异常检测、PHM库存健康评估
> 算法：ARIMA时序消耗预测、孤立森林异常检测、PHM库存健康评估
> 说明：本系统为课程演示Demo，无真实硬件对接，AGV模块预留扩展接口，当前版本优先完成物料出入库、模拟数据生成、库存预测与健康评估功能。

## ✨ 项目功能
1. **物料出入库管理**
支持手动对物料执行入库、出库操作，实时更新库存数量，记录每一条操作日志。
2. **一键模拟出入库数据**
页面内置模拟按钮，点击自动批量生成历史出库记录，快速构建数据集，用于后续时序预测计算。
3. **ARIMA时序预测**
基于历史出库记录，预测物料未来7天的物料消耗量，并结合安全库存自动计算建议补货数量。
4. **孤立森林异常检测**
使用IsolationForest机器学习算法，自动识别异常出入库操作，在明细页面标红展示异常记录。
5. **PHM库存健康状态评估**
综合预测消耗、安全库存、当前库存三个指标，自动判定库存健康等级：`正常` / `积压风险` / `短缺风险` / `数据不足`。
6. **现代化Web UI**
卡片布局、阴影样式、状态颜色区分、表格hover高亮，界面简洁美观。
7. **预留扩展**
项目预留AGV任务数据表结构，后续可扩展蚁群算法AGV路径规划、LSTM时序预测、Apriori关联规则挖掘模块。

## 🚀 项目运行教程
### 1. 安装依赖包
```bash
pip install -r requirements.txt
```

### 2. 初始化物料基础数据

```
python init_data.py
```

执行脚本自动向数据库插入 5 种基础物料。

### 3. 启动 Web 服务

```
python main.py
```

### 4. 浏览器访问系统

打开浏览器，访问地址：

```
http://127.0.0.1:8000
```

## 📖 基础使用操作流程

1. 首页查看所有物料信息，手动执行入库、出库操作，实时更新库存；
2. 点击【自动模拟出入库数据】按钮，一键批量生成历史出库样本，满足时序预测的数据量要求；
3. 进入【智能 AI 分析面板】，查看 ARIMA 预测 7 天物料消耗、系统自动算出的建议补货量、PHM 库存健康状态；
4. 点击【查看异常记录】，浏览物料全部出入库明细，红色条目为算法识别出的异常操作；
5. 数据表预留 AGV 任务字段，后续可扩展配送任务生成与 AGV 路径仿真功能。

## 🧠 技术栈与算法说明

- Web 后端框架：FastAPI + Uvicorn
- 数据库：SQLite + SQLAlchemy ORM
- 时序预测算法：ARIMA（statsmodels）
- 异常检测算法：孤立森林 IsolationForest（scikit-learn）
- 库存健康评估：PHM 健康状态评估
- 数据处理：Pandas
- 前端页面：原生 HTML + CSS

> 
> 后续扩展算法：LSTM 时序预测、Apriori 关联规则挖掘、蚁群算法 AGV 路径仿真

## ⚠️ 重要注意事项

1. ARIMA 时序预测需要**至少 6 条出库历史记录**，才能输出预测结果，使用页面模拟按钮可快速生成足量出库数据。
2. gh.db 数据库文件不会提交到代码仓库，在新环境首次运行项目会自动新建数据库。
3. 修改代码后需要重启服务，改动才能生效。
4. 当前版本为阶段性 Demo，AGV 调度、LSTM、Apriori 模块为预留扩展项，待后续迭代开发。
